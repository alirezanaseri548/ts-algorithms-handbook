# Step 36: Singly Linked List Summary

- `append(value)` adds at the end.
- `read(index)` returns the value at an index or `null`.
- `indexOf(value)` returns the index of a value or `-1`.
- `insertAtIndex(index, value)` inserts a node at a position.
- `deleteAtIndex(index)` removes a node at a position.
- `length()` returns the current size.
- `toArray()` is useful for inspection and debugging.
