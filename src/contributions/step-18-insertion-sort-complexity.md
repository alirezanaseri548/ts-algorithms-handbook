# Insertion Sort Complexity

Insertion Sort builds a sorted section from left to right. Each new value is inserted into its correct position inside the sorted section.

## Big O

- Best case: O(N)
- Average case: O(N^2)
- Worst case: O(N^2)
- Space complexity: O(1)

Insertion Sort is adaptive. It performs very well when the array is already sorted or nearly sorted.
