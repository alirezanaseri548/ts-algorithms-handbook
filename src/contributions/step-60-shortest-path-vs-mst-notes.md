# Step 60 — Shortest Paths vs Minimum Spanning Trees

Shortest-path algorithms and MST algorithms solve different optimization problems.

- A shortest path minimizes the total weight between selected vertices.
- An MST connects all vertices with minimum total edge weight and no cycles.
- An MST path between two vertices is not necessarily their shortest path.
- Bellman-Ford works with directed graphs and negative edges.
- Kruskal works with weighted undirected graphs.
