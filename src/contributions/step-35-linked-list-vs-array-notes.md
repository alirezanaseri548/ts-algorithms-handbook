# Step 35: Linked List vs Array

## Read by index
- Array read is O(1)
- Singly linked list read is O(n)

## Search
- Array search is O(n)
- Singly linked list search is O(n)

## Insert
- Array insertion in the middle is O(n)
- Linked list insertion at the head is O(1)
- Linked list insertion at an index is O(n)

## Delete
- Array deletion in the middle is O(n)
- Linked list deletion at the head is O(1)
- Linked list deletion at an index is O(n)

## Takeaway
- Arrays are better for direct indexing.
- Linked lists are useful when pointer updates matter more than indexed access.
