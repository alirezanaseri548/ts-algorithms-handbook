# Linked List — نکات پیاده‌سازی و خطاهای رایج

## چرا Linked List؟

| عملیات            | Array   | Linked List |
| ----------------- | ------- | ----------- |
| درج/حذف در ابتدا  | O(n)    | O(1)        |
| درج در انتها      | O(1)*   | O(1) با tail |
| دسترسی با ایندکس  | O(1)    | O(n)        |
| حذف از میانه      | O(n)    | O(n) پیمایش + O(1) اتصال |

## خطاهای رایج

1. **فراموش‌کردن به‌روزرسانی `tail`**
   وقتی آخرین عنصر حذف می‌شود باید `tail` هم `null` شود، وگرنه لیست خالی همچنان به یک Node مرده اشاره می‌کند و درج بعدی نتیجه‌ی نادرست می‌دهد.

2. **نگه‌داشتن `next` روی Node حذف‌شده**
   بعد از حذف حتماً `removed.next = null` قرار دهید تا Garbage Collector بتواند زنجیره را آزاد کند.

3. **ترتیب اشتباه در `unshift`**
   ابتدا `node.next = head` و سپس `head = node`. عکس این ترتیب کل لیست را از دست می‌دهد.

4. **حلقه‌ی بی‌پایان در پیمایش**
   شرط حلقه باید `current !== null` باشد، نه `current.next !== null`؛ در حالت دوم آخرین Node پردازش نمی‌شود.

5. **استفاده از `Array.shift` به‌جای صف پیوندی**
   `shift` روی آرایه O(n) است. برای صف با حجم بالا از `LinkedListQueue` استفاده کنید.

6. **`length` ناهماهنگ**
   هر مسیر خروج از متدهای درج/حذف باید دقیقاً یک بار `length` را تغییر دهد.

7. **در Doubly Linked List فراموش‌کردن `prev`**
   هر اتصال دوطرفه است: هم `a.next = b` و هم `b.prev = a`.
